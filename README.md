# Online Retail：客户分群与复购预测

基于 Online Retail 交易数据，完成数据清洗、探索性分析、RFM 客户分群与 XGBoost 复购预测，比较加入 RFM 相关特征前后的模型表现。

## 数据处理与探索分析

数据覆盖 2010-12-01 至 2011-12-09，字段包括订单号、商品编号、商品描述、数量、交易时间、单价、客户编号和国家。

- 删除客户编号缺失的记录，去除完全重复的行；已有输出显示清洗后保留 **401,604 条交易明细**。
- 将交易时间转为日期时间类型，客户编号转为整数。
- 保留零单价记录，将其视为可能的赠品，这属于分析假设。
- 新增金额字段 `TotalPrice = abs(Quantity × UnitPrice)` 和取消标记 `cancelled = Quantity < 0`。

探索分析包括字段相关性、各国交易金额、明细金额分布、销量前十商品、商品取消率和复购率，以及日、月、星期和小时维度的金额变化。商品取消率按明细行计算，至少保留 20 条记录；商品复购率按客户是否有多张不同订单计算，至少保留 20 位客户。

## RFM 客户分群

参考时点为最晚交易时间加 1 天再减 90 天，已有输出为 **2011-09-11 12:50:00**。仅使用该时点及之前的记录，得到 **3,418 位客户**。

| 指标 | 计算方式 | 高评分含义 |
| --- | --- | --- |
| Recency | 距最近交易的整数天数 | 最近有交易 |
| Frequency | 不同订单号数量 | 交易频繁 |
| Monetary | 交易金额合计 | 累计金额高 |

采用五分位评分，R 分数反向，F 先用排名处理重复值。根据评分划分为高价值客户、潜在忠诚客户、大额消费客户、新客户、忠诚客户、普通客户、高消费风险客户、流失或休眠客户八类。已有输出中，高价值客户为 758 人，流失或休眠客户为 1,370 人。

聚类部分对 R、F、M 做 `log1p` 变换和标准化，通过肘部法与轮廓系数辅助选择聚类数，最终使用四类 K-Means 聚类，随机种子为 42。通过交叉表、热力图和卡方检验比较两种分群方式。

**口径说明：** 当前 RFM 流程包含取消记录，金额按绝对值累计，Monetary 不能直接解释为净销售额。导出的 `rfm.csv` 中 R、F、M 已被覆盖为对数变换后的值。聚类名称 `Persona` 为手工映射，需结合统计结果核对业务含义。

## 未来复购预测

文件名虽然为“用户流失预测”，代码实际预测客户在未来观察窗口内是否再次购买。标签 `future_purchase` 中，**1 表示复购，0 表示未复购**。未复购可作为潜在流失信号，但不代表永久流失。

预测时保留数量大于 0 且未取消的交易。参考时点及之前为历史窗口，用于构造特征；参考时点之后至数据结束为未来窗口，用于生成标签。建模对象为历史窗口中已出现的客户。

数据按标签分层随机划分为训练集、验证集和测试集，比例约为 **70% / 15% / 15%**，随机种子为 42。

| 方案 | 特征 |
| --- | --- |
| 直接聚合特征 | 总消费金额、订单数、平均订单金额、总购买数量、平均每单商品数量 |
| 加入 RFM 特征 | 上述五项，加上 Recency、R 评分、F 评分和 M 评分 |

评分分位点仅由训练集计算，再应用于验证集和测试集，独立于 RFM Notebook 的评分结果。

模型使用 XGBoost：最多 1,000 棵树，学习率 0.05，最大深度 6，行、列采样比例均为 0.8。根据验证集 AUC 早停，耐心值为 50 轮，分类阈值为 0.5。
